# github-101

零基础 GitHub 练习仓库：从 0 走通「建仓库 → commit → push → PR → 发版」全流程。

## 这个仓库是干什么的

- 记录 GitHub 的核心概念与操作要点（见 `notes/`）
- 作为第一个练习项目，验证本地 git 与 GitHub 的完整链路
- 后续可替换为真实项目

## 核心概念速查

| 概念 | 一句话 |
|---|---|
| Repository | 仓库，代码 + 全部提交历史 |
| Commit | 一次保存（快照） |
| Branch | 分支，多人并行开发互不打扰 |
| Pull Request | 请求把你的分支合并进主干，合并前可审查 |
| Tag / Release | 给某个 commit 打版本号 / 发布成品 |
| Star / Fork / Watch | 收藏点赞 / 云端复制副本 / 订阅动态 |
