# GitHub 学习笔记 01 · 四三七四

> 来源：抖音《Github 零基础终极教程》37:30 版，整理取要点。口诀：**4-3-7-4**。

## 4 种找资源的方法

1. **Trending 榜**：Explore → Trending，按日/周/月看最热门项目
2. **关键词搜索**：顶部搜索框，已知项目名时最快
3. **问 AI**：只描述功能让 AI 推荐（最适合"知道要什么、不知道叫什么"）
4. **第三方站点 / 自媒体推荐**

## 3 个核心指标

| 指标 | 作用 | 何时点 |
|---|---|---|
| Watch | 订阅项目全部动态 | 深度参与时 |
| Fork | 在自己账号下建完整副本 | 要二次开发 / 提 PR |
| Star | 收藏 + 给作者点赞 | 想存下来以后用 |

## 7 种开源许可证（从宽松到严格）

MIT → BSD-3-Clause → Apache-2.0 → MPL-2.0 → LGPL-3.0 → GPL-3.0 → AGPL-3.0

- 前 3 种宽松：可闭源商用，但要保留版权/许可声明（Apache 还有专利与 NOTICE 义务）
- 中间 4 种传染性递增：修改/分发/在线服务可能要求开源
- ⚠️ **仓库没有 LICENSE = 默认保留所有权利，法律上不可复用**

## 4 种下载 / 使用方式

| 方式 | 拿到什么 | 适合 |
|---|---|---|
| Release | 成品安装包（dmg/exe） | 只想用软件 |
| Download ZIP | 源码压缩包（无历史） | 只想读代码 |
| git clone | 本地完整仓库，可 pull 更新 | 长期开发 |
| Fork | 云端副本 | 改完提 PR 贡献 |

## 开源自己的项目（8 步）

1. 建项目目录 → 2. 开发 → 3. 写 README → 4. 加 LICENSE → 5. **安全检查（密钥/隐私/路径）** → 6. git init + commit → 7. 建远端仓库并 push → 8. 打 tag 发 v0.1.0 → 维护 Issues / PR

## 安全红线

开源前必须确认不含：密码 / token / 私钥、个人隐私、本地绝对路径、临时文件、内部资料。
